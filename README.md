# StreamOM — Stream Operations Manager

Plataforma SaaS multi-tenant y white-label de operación radial profesional: streaming externo, programación editorial, biblioteca multimedia, playout administrado, emisión en directo, audiencia y administración.

Estado: discovery y preparación documental, greenfield. No hay implementación todavía. La marca comercial requiere validación jurídica.

## Contexto para ejecutores

- [AGENTS.md](AGENTS.md): reglas obligatorias.
- [OpenSpec](openspec/config.yaml): contexto y reglas de cambios.
- [Documentación](docs/README.md): índice de producto, arquitectura, seguridad y entrega.

La construcción comienza por M00 Platform Foundation. Cada módulo requiere refinamiento y Definition of Ready antes de abrir trabajo ejecutable. Los wireframes se elaboran y exportan por módulo, no todos por adelantado.
