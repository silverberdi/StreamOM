# Business intent and scope
StreamOM (Stream Operations Manager; working name, trademark/domain validation pending) is a professional radio operations SaaS serving small external-stream stations through fully managed operations. Core includes weekly scheduling, shows, clocks, rotations, fixed/dynamic slots, media, playout, live, fallback, metadata, audience, administration. A playlist plus stream is insufficient.
## Customer model
Hybrid onboarding: autonomous registration, draft station, controlled entitlement activation. Basic external-stream trial without automatic costly media provisioning; managed playout/storage/live require explicit entitlement. Profiles External Basic, External + Redundancy, Managed, Managed + Live, Professional/Custom are conceptual, not commercial pricing. Manual subscription administration initially, automated entitlement enforcement and usage tracking, payments deferred.
White-label public pages/PWA per station, configurable brand/domain, no separate application deployment per client. Anonymous listening by default. Platform branding governed by plan.
## Actors
Platform administrator/support; tenant owner/admin; station owner/admin; programming director; content manager; DJ/host; analyst; anonymous listener. Advertiser role deferred. Multiple memberships, explicit scope.
## Success
Operate external or managed radio end-to-end, maintain continuity where configured, show truthful metrics, isolate tenants, deliver professional UI from first executable prototype. No fake analytics or unimplemented claims.
