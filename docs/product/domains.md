# Domain baseline (accepted and delegated discovery)
## Station lifecycle
Station belongs to exactly one tenant and has exactly one effective owner. Tenant owner controls organization and can recover station administration through explicit audited action. Create tenant/station/ownership atomically for self-service. Identity: name, unique scoped slug/routing identity, timezone, language, optional branding/domain. Onboarding is persistent resumable workflow with sections NOT_STARTED/IN_PROGRESS/COMPLETE/NEEDS_ATTENTION, not lifecycle state.
Lifecycle DRAFT, ACTIVE, SUSPENDED, ARCHIVED, DELETION_PENDING, DELETED. Readiness NOT_CONFIGURED, CONFIGURING, READY, DEGRADED, BLOCKED; operational NOT_STARTED, STARTING, ON_AIR, DEGRADED, OFFLINE, STOPPING. Independent public publication state. Source Router AUTOMATED, EXTERNAL, WEB_LIVE, OBS_LIVE, FALLBACK, OFFLINE. Active does not imply on-air or published. Readiness derived from PASS/WARNING/FAIL/N/A checks. Nonblocking warnings need no override; only explicitly overrideable degraded conditions can be overridden by privileged actor with reason; blocked never activates. Activation explicit; publication and start separate. External readiness requires reachable playable audio; enriched credentials optional. Managed readiness requires playable media, valid programming/plan, output and assigned node.
Suspension administrative not technical failure; block operations, revoke live, stop controlled broadcast, disable public experience, retain data. External server cannot be stopped by us. Reactivation after reason resolved and readiness recheck. Archive stops operations, retains configuration and assets per policy; restore to DRAFT, revalidate, explicit activation. Delete only from draft/archive, recoverable pending state, then terminal purge/anonymization per policy; cancellation restores previous recoverable state. Retention period pending. Archive/delete during live must explicitly stop and confirm. Owner transfer atomic within tenant, target acceptance where invited, former owner role explicit; no last-owner removal. Cross-tenant transfer and clone deferred. Custom domain verification independent (NOT_CONFIGURED/PENDING_VERIFICATION/VERIFIED/ACTIVE/ERROR); standard URL remains available. Audit all privileged transitions and reason where sensitive.
Primary mode EXTERNAL_STREAM or MANAGED_PLAYOUT, capabilities independently entitled. Prepare target without disrupting current source, validate, controlled switch, verify and restore old configuration on failure. Operational source switching does not change primary mode.
## External / metadata
Direct External listeners connect to provider; Routed External requires entitlement and controlled routing infrastructure. Basic URL, availability, retries, public metadata; enriched provider API may expose mount/source, listeners, bitrate, codec, uptime, statistics. ExternalStreamProvider abstraction. No promise of seamless switching on uncontrolled direct streams. Fallback optional per station: retry only, secondary stream, managed emergency playlist/loop as configured. Source transitions idempotent, governed, audited.
NowPlayingSnapshot stationId/sourceType/title/artist/album/artwork/contentType/startedAt/expectedEndAt/externalReference/confidence/updatedAt. Configurable precedence provider API, ICY, webhook/API, manual/scheduled, Unknown/Station Live. Publish normalized events; clients never parse raw provider format. Actual managed playback events drive metadata.
## Media library
Tenant-owned MediaAsset with explicit station assignments; shared physical file within tenant, station-specific editorial categories/pools; no cross-tenant dedup or visibility. MediaFile immutable master, MediaRendition regenerable, versions retain stable asset ID. Types MUSIC/JINGLE/STATION_ID/PROMO/ADVERTISEMENT/NEWS/VOICE_TRACK/PROGRAM/SOUND_EFFECT/OTHER. Emergency is policy assignment.
Individual/bulk drag-drop upload; quota reservation, async processing, checksum, integrity and decode checks, technical metadata, loudness/true peak, rendition. Completed uploads continue after browser closes. Partial batch success; corrupt files isolated; retry failed; temporary original retention pending. Inputs MP3/WAV/FLAC/AAC-M4A/OGG candidates; Opus validation pending; WMA deferred. URL import pending; external storage import/watched folders/migrations deferred. Artwork, tags, genre, album, artist identity and aliases; ambiguous matches never auto-merge. Manual metadata > explicit import > embedded > provisional filename; reprocessing preserves manual edits. Technical metadata read-only from analysis. Checksum exact duplicate reuse tenant-only; acoustic fingerprint deferred; title/artist similarity warning only.
Lifecycle ACTIVE/ARCHIVED/DELETION_PENDING/DELETED; ingestion UPLOADING/UPLOADED/PROCESSING/COMPLETED/FAILED/CANCELLED; availability NOT_READY/AVAILABLE/UNAVAILABLE; editorial UNCLASSIFIED/CLASSIFIED. Unclassified playable manually if authorized, not automatically in pools. Static and dynamic pools, preview counts; categories/tags/genres distinct; playlists ordered; rotation rules in Programming. AvailableFrom/Until, station assignment and rights restrictions are hard eligibility. No new automatic playback of expired asset. Versions process before activation; old remains working if failure; current playback immutable; planned references pinned until controlled regeneration; duration changes trigger review. Dependency checks across stations before archive/delete/desassign; no silent broken references; wait for current playback unless authorized emergency. Tenant asset survives station deletion while referenced. Storage objects private, DB metadata only, quota reservation transactional. Bulk metadata/category/station assignment, search/filter/pagination, persistent private preview (never on-air), upload queue, retries, dependency view. Waveform detailed and audio editing deferred.
## Programming
Weekly schedule, shows, date exceptions, clocks, fixed and dynamic slots, playlists, pools, rotations, jingles/IDs/promos/ads/news/voice, live windows, overrides. .NET decides, Liquidsoap executes. Draft/simulate/validate/publish versioned schedule, generate rolling plan, daily log, playback history actual vs planned. Rotation considers actual history plus future reservations; artist/song separation, weights, least-used preference. Hard constraints: rights, validity, assignment, corruption, admin/security. Flexible rules only relax if explicitly allowed; log reason. Precedence safety > authorized emergency > authorized live/override > date exceptions > mandatory timed items > weekly/flexible > dynamic > configured fallback, subject to router authorization. Hard Time strict boundary with controlled transition when permitted; Soft Time finishes current content within configured tolerance. No unnecessary cuts by default. Empty pool alternative authorized; all rules strict/no eligible -> configured fallback/offline; duration unknown excluded; playback failure skip valid next; overrun adjust flexible slots preserving mandatory; late news substitute authorized or skip; empty ad break fill eligible non-ad; underrun fill configured pool; locked items preserved unless invalid; invalid asset triggers controlled regeneration; changes version future affected segments, protect current/committed items; late live continue main; early live end resume current time, not stale plan. Exact tie-breaking, clock math, tolerances, horizon, DST edge cases require M06 refinement.
## Managed broadcast and live
Liquidsoap executes audio, transitions, fallback, encoding, outputs, ingest. Assign station to node without permanent coupling; no active-active MVP. Source Router single canonical active source with exclusion and fencing/confirmation design pending. Health checks heartbeat, connection, ingest, silence policy (distinguish deliberate silence). DJ invited, assigned station/show, prepares privately, tests mic, selects device, levels, connection, countdown, requests takeover within authorized window without second approval; outside window explicit override. One active live source; one ingest session per DJ/station; no unauthorized displacement. States CREATED/PREPARING/READY/TAKEOVER_PENDING/ON_AIR/RECONNECTING/ENDING/ENDED/FAILED. ON_AIR only on router confirmation. Disconnect policy configurable, fallback and alerts; reconnection revalidates permission and source availability before reclaiming air. End of window controlled return unless authorized extension. Revocation terminates controlled session. WebRTC browser; OBS RTMP; SRT early if validated. Credentials scoped, rotatable, revocable. Metadata manual, mic mute, private test, level meter; no complex return monitor initially. Recording, multiparty interviews/green room, professional mixer deferred. All takeover/override/return audit actor, station, source, time, reason.
## Public
React PWA white-label standard URL/custom domain, per-station manifest identity/scope/icons. Anonymous play/pause, volume where supported, now/next, schedule, show detail, recent history if known, artwork fallback, share, local favorites, media session/lock screen/background playback where supported. Playback persists across internal navigation, pause returns to live edge, explicit user gesture if required. Controlled retries, offline cached UI never fake audio, suspended generic unavailable, quality selection only with multiple compatible outputs. No arbitrary customer HTML/JS. Listener account, synced favorites, directory, native apps, on-demand/chat deferred. Publication separate from active/on-air.
## Analytics
PWA listening events, provider metrics and managed server stats with source/coverage/time/confidence; no double counting PWA/server. Concurrent total only when source supports it; estimated unique devices/sessions not exact people. Duration, geography approximate, device/browser/referrer, peaks, program/song correlation not causal, live vs auto, export CSV, history/dashboard. No GPS or invasive fingerprinting; consent where applicable, minimized personal data, tenant isolation. Analytics async, failure never blocks playback. PostgreSQL initial aggregates candidate, migration threshold/retention pending. Audience metrics distinct from billable resource usage.
## Administration, roles and commercial
Global console separate from station. Tenants/stations/nodes/incidents/support/entitlements/flags/audit/usage. SupportSession scoped, time-bound, reason, read-only default, extra explicit write permission, true actor identity, revoke and audit, no silent impersonation or secret/master access. Emergency privileged path separately audited. Incidents OPEN/ACKNOWLEDGED/INVESTIGATING/MITIGATED/RESOLVED/CLOSED, severity critical/high/medium/low, dedup repeated cause, distinguish external vs owned infrastructure.
Platform, tenant, station roles predefined and additive; custom roles deferred. Deny by default, no self-escalation, scoped capabilities and entitlement checks. Owner controls archive/delete/transfer; station admin config/team/operation not ownership; programmer schedule/clocks/pools/publish; content manager upload/edit; DJ preview and authorized live; analyst analytics. Tenant shared asset privileges separately evaluated. Detailed capability matrix per module. Plan/Subscription/Entitlement/ResourceLimit/UsageRecord/Trial/Override separate from feature flags. Meter stations/users/DJs/storage/transfer/concurrency/processing/playout/live/quality/retention/integrations. Quotas block new allocations, no automatic deletion/downgrade damage, no arbitrary current stream cutoff for storage. Grace/suspension/admission policies pending. Manual commercial administration, no cards or fiscal engine, payments later.
