# UX constitution
No ugly provisional CRUD; every executable UI uses agreed frameworks from birth. Angular + PrimeNG + Tailwind consoles; React + Tailwind public. Shared tokens, spacing, typography, reusable components, clear/dark themes, responsive, WCAG 2.2 AA target, loading/empty/error/feedback, keyboard access. Admin desktop-first dense but readable, broadcast status persistent, dangerous actions distinct; public mobile-first, configurable validated branding; animations functional. Spanish/English initial, station timezone with DST.
## Navigation
Station Console: Overview/readiness; Programming (weekly schedule/shows/clock builder/rotations/daily log/exceptions); Media Library (detail/uploads/categories/pools); Broadcast (sources/router/fallback); Live (agenda/sessions/studio/OBS); Audience; Team; Integrations; Settings (identity/brand/domain); Usage & Plan; Audit.
Platform Console: overview, tenants, stations, nodes, commercial, support, incidents, security/audit, flags/config. Live Studio focused layout: preparation, private audio test, on-air, reconnect, ending. Public: player, schedule, show detail, recent, favorites, about, install, unavailable.
## Visual workflow
Wireframes are NOT required globally upfront. For each module refine behavior, generate/validate wireframes (Stitch if available), export PNG/HTML and necessary assets into repo or issue attachments (not just external links), create ready issue, implement, verify visual fidelity. No wireframes generated yet. M00 establishes design foundations without inventing dummy functionality. Module UI cannot pass Verify on bare HTML or missing states.
