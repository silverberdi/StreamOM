# Architecture and contracts
.NET 10 LTS modular monolith control plane; Angular/PrimeNG/Tailwind administrative console and React/Tailwind public PWA. PostgreSQL canonical relational store, schemas platform/station, native UUID (v7 preferred when cleanly supported), jsonb only genuinely flexible data; EF Core + Dapper behind persistence contracts. Tenant-scoped rows tenant_id NOT NULL; application authorization first, RLS second, normal roles respect RLS; controlled privileged cross-tenant path, audited. Object storage S3-compatible private masters/renditions/artwork. FFmpeg/FFprobe isolated processing. Docker Linux self-hostable Ubuntu, portable cloud. Static frontend, API/workers, reverse proxy HTTPS, broadcast nodes separate logical plane. No Kubernetes/service mesh/Kafka/RabbitMQ/Redis by default; no active-active. Node caches valid plan during bounded authorized outage; lease duration/fencing pending.
ExternalStreamProvider, StreamDistributionProvider, LiveSource abstractions. HTTP Icecast/direct distribution (not WebRTC mass audience); future HLS/CDN. .NET Programming Engine creates plan; Liquidsoap executes. WebRTC/RTMP ingest, SRT candidate; MediaMTX candidate, LiveKit/multiparty deferred. AAC 64/128 kbps and MP3 compatibility candidates, Opus WebRTC candidate; full end-to-end spike before selection.
## Domain ownership
Identity users/sessions; Tenancy memberships; Station config/lifecycle; Media assets/versions; Programming schedule/plan; Broadcast router/source state; Live sessions; NowPlaying normalized snapshot; Analytics metrics; Entitlements subscription/limits; Audit evidence; Public publication/branding. No direct mutation of another domain's internal entities.
## Events
StationCreated/Activated/Suspended/Reactivated/Archived/Restored/Deleted, OwnershipTransferred, ReadinessEvaluated, PrimaryBroadcastModeChanged; MediaUploadCompleted/ProcessingStarted/ProcessingCompleted/ProcessingFailed/AssetAvailable/AssetUnavailable/MetadataUpdated/VersionActivated/StationAssignmentChanged/PoolChanged/AssetExpired/AssetArchived/AssetRestored/DeletionRequested/AssetDeleted (prefix Media); SchedulePublished, PlayoutPlanGenerated, PlaybackStarted/Completed/Failed, LiveTakeoverCompleted, LiveConnectionLost, SourceChanged, EntitlementChanged, StationPublished, ResourceLimitReached. Names are conceptual, schema/version/contracts to refine before implementing.
Events versioned, idempotent, correlation and tenant/station context, reliable PostgreSQL transactional outbox. Programming consumes media availability/expiry; Broadcast consumes published plans and station/entitlement changes; NowPlaying/Analytics consume playback/source/live events; Audit and Operations consume sensitive actions/failures. Ownership/quota/role assignment transactional; publication transactional/versioned; takeover exclusive confirmed; analytics/notifications eventual; media jobs async. Define replay, retries, ordering, fencing and error contracts per module.
